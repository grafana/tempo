# Release notes

Release notes provide a curated list of the latest features, enhancements, and bug fixes for Grafana Tempo. For a complete list, refer to the [CHANGELOG](https://github.com/grafana/tempo/blob/main/CHANGELOG.md) for the release.

{{< admonition type="note" >}}
To view release notes for a previous version, select **Find another version** in the left sidebar, choose the version you want, and then select **Go to page**.
{{< /admonition >}}

Packages are linked in the [Assets section for each Tempo release](https://github.com/grafana/tempo/releases). Packages include the binaries, source code, and documentation for the release.
